**Nội dung:**

- Khó khăn khi không có signature.
    
- Sử dụng luật chung (Generic Rules) để phát hiện các mẫu tấn công phổ biến (ví dụ: SQLi).
    
- Ví dụ về luật Talos cho SQLi: `xp_cmdshell`, `union select`, `1=1`.
    
- Quy trình: Phân tích log Snort -> Xác định các rule ID bị kích hoạt -> Dùng script Python để trích xuất luật gốc.
    
- Tầm quan trọng của việc phân tích các giai đoạn tấn công (probing vs. exploitation).
